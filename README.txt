SetupCheck - Landing Page (solo parte visual)
=============================================

Cómo abrirlo en Visual Studio Code:
1. Descomprime la carpeta y ábrela con VS Code (Archivo > Abrir carpeta).
2. Instala la extensión "Live Server" (si no la tienes).
3. Click derecho en index.html > "Open with Live Server".
   (También funciona abriendo index.html directamente en el navegador).

Estructura:
- index.html ............ Inicio
- css/styles.css ........ Estilos de todas las páginas
- js/script.js .......... JavaScript (por ahora vacío, la página es solo visual)
- img/ .................. Carpeta para imágenes (todavía sin usar)
- paginas/ .............. Resto de pantallas del Figma:
    hardware.html ................... Hardware: componentes y categorías
    benchmarks.html ................. Repositorio: inicio (E2-P1)
    benchmarks-buscar.html .......... Benchmarks con buscador y botón de filtros
    filtros.html .................... Panel de filtros abierto
    sin-resultados.html ............. Búsqueda sin resultados
    resultados.html ................. Resultados con filtros (E2-P2)
    detalle-reporte.html ............ Detalle del reporte (E2-P3)
    comparar.html ................... Comparar configuraciones
    reporte-captura.html ............ Reporte con captura y votos
    captura-original.html ........... Captura original ampliada
    ranking.html .................... Ranking y reputación (E2-P5)
    reporte-compartido.html ......... Reporte compartido y ventana (E2-P6)
    simulador.html .................. Simulador: inicio
    simulador-componentes.html ...... Paso 1: seleccionar componentes
    simulador-analisis.html ......... Paso 2: análisis
    simulador-resultado.html ........ Paso 3: resultado final
    como-funciona.html .............. Tutorial web + preguntas frecuentes
    como-funciona-mobile.html ....... Tutorial mobile + preguntas frecuentes
    comunidad.html .................. Comunidad
    aportar-subir.html .............. Aportar reporte, paso 1
    aportar-leyendo.html ............ Aportar reporte, paso 2
    aportar-publicar.html ........... Aportar reporte, datos detectados
    aportar-publicado.html .......... Aportar reporte, paso 3
    login.html / registro.html / 404.html

Nota: las fotos de los tutoriales (laptop y celular) del Figma se reemplazaron
por bloques de color. Para ponerlas, guarda las imágenes en la carpeta img/.
